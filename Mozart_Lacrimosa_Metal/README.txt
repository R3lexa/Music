ЧТО ВНУТРИ ЗВУЧИТ (аранжировка)
--------------------------------
Мелодия взята ТОЧНО из подлинной партитуры Реквиема K.626
(сверено по оригинальной MIDI-партитуре: сопрано, бас, струнные):

  00:00  Интро      — струнное остинато (тот самый «слёзный пульс»
                      из оригинала), орган, тихая литавра, хор вступает
  00:08  Тема       — «Lacrimosa dies illa»: A4–F5–D5–D5–C#5
                      хор + ритм-гитары (палм-мьют), грув бочка/рабочий
  00:16  Подъём     — «qua resurget ex favilla»: восходящая гамма
                      D4-E4-F4-G4 | A4-B4-C5-D5, аутентичный бас F-E-A-G
  00:24  Judicandus — хроматическая лестница Моцарта D#5-E5-F5-F#5-G5-G#5-A5,
                      ДВОЙНАЯ БОЧКА триолями (KKK-KKS), стена гитар,
                      лид-гитара с вибрато, контрапунктный бас C-Bb-A
  00:33  Кульминация— хроматика уходит к ля (A5), хор фортиссимо,
                      аккорд A7 с «рыдающей» низкой ноной
  00:37  Развязка   — каденция «reus» + переход
  00:41  Pie Jesu   — эхо темы, хор умоляюще затихает, литавры
  00:56  Кодета     — барабанное крещендо, ролл литавр
  01:00  ФИНАЛ      — удар D-moll: хор, гитары, двойной крэш,
                      литавры D, суббас D1, хвост реверберации

ТЕХНИЧЕСКИЕ ДЕТАЛИ
------------------
  • Темп: 12/8, четверть = 88 BPM (восьмая = 176/мин)
  • Тональность: ре минор (как в оригинале)
  • Синтез: полностью программный (numpy): гитары с перегрузом
    и каб-симуляцией, лид с вибрато, бас, драм-машина, 4-голосный
    хор с формантами «а», струнный ансамбль, орган, литавры,
    FFT-реверберация зала 2.6 сек
  • Мастеринг: highpass 26 Гц, мягкий клей, пик −0.4 дБ
